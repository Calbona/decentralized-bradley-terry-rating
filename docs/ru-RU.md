# Децентрализованный рейтинг Брэдли–Терри

Для обновления рейтинга после матча нужны только текущие рейтинги двух игроков и результат. Ни центрального сервера, ни общего журнала матчей, ни идентификаторов игроков. В репозитории две семантически идентичные реализации — на TypeScript и C#; обе построены на чистых функциях.

## Модель

Рейтинг `r ∈ (0, 1)` — это относительная доля побед игрока: вероятность обыграть нейтрального соперника с рейтингом `r = 0.5`. Ей соответствует сила Брэдли–Терри

```
γ = r / (1 - r)
```

Прогноз для матча двух игроков:

```
P(A побеждает B) = γA / (γA + γB)
                 = rA(1 - rB) / (rA(1 - rB) + rB(1 - rA))
```

Здесь `θ = logit(r) = log(γ)`, `p = P(A побеждает B)`, `s = 1`, если победил A, и `0` в противном случае, а `η` — скорость обучения:

```
θA' = θA + η · (s - p)
θB' = θB - η · (s - p)
r'  = σ(θ')
```

Это один шаг онлайн-градиентного подъёма по глобальному логарифмическому правдоподобию Брэдли–Терри, то есть Elo в логарифмических шансах. Значение по умолчанию `η = 0.25` примерно соответствует шахматному `K ≈ 43` (`η = K · ln 10 / 400`).

При фиксированной скорости обучения онлайн-обновление стабилизируется в `O(η)`-окрестности глобального решения. Для строгой сходимости к решению максимального правдоподобия уменьшайте скорость с ростом числа матчей `t`, например `η_t = η0 / (t + τ)`. Библиотека не хранит состояние, так что расписание задаёт вызывающий код.

## Свойства

1. **Ограниченность** — входы и выходы всегда строго лежат в `(0, 1)`. Ни отрицательных долей побед, ни значений больше 100%.
2. **Нейтральность при 0.5** — `r = 0.5` означает равную игру с нейтральным соперником; с этого значения начинают все новые игроки.
3. **Симметрия** — поменяйте игроков местами и инвертируйте результат, и новые рейтинги поменяются так же. `P(A побеждает B) + P(B побеждает A) = 1`.
4. **Монотонность** — рейтинг победителя растёт, рейтинг проигравшего падает.
5. **Сенсации весят больше** — неожиданный результат сдвигает рейтинги сильнее ожидаемого, поэтому победа над сильным соперником приносит больше, чем над слабым.
6. **Нулевая сумма в логарифмических шансах** — `θA' + θB' = θA + θB`. Матч никогда не меняет сумму логарифмических шансов пары, поэтому весь набор рейтингов не дрейфует. Если все стартуют с 0.5, сумма всех `θ` остаётся равной 0 — ровно та нормировка, что используется в глобальном решении максимального правдоподобия Брэдли–Терри.
7. **Сходимость** — каждое обновление идёт вдоль градиента глобального логарифмического правдоподобия Брэдли–Терри. Если уменьшать скорость обучения так, чтобы выполнялись условия Роббинса–Монро, рейтинги сходятся к глобальной оценке максимального правдоподобия; тесты проверяют это по эталонной MLE, вычисленной алгоритмом MM.

## Ничьи

У матча ровно два исхода: побеждает A или побеждает B. Если в вашей предметной области нужны ничьи, не передавайте их в библиотеку как есть.

## Быстрый старт

TypeScript:

```ts
import {
  INITIAL_RATING,
  updateRatings,
  winProbability,
} from 'decentralized-bradley-terry-rating';

const ratings = new Map<string, number>([
  ['alice', INITIAL_RATING],
  ['bob', INITIAL_RATING],
]);

const a = ratings.get('alice')!;
const b = ratings.get('bob')!;

// alice побеждает
const { ratingA, ratingB } = updateRatings(a, b, true);
ratings.set('alice', ratingA);
ratings.set('bob', ratingB);

console.log(winProbability(ratingA, ratingB)); // обновлённый прогноз
```

C#:

```csharp
using DecentralizedBradleyTerry;

var ratings = new Dictionary<string, double>
{
    ["alice"] = Ratings.InitialRating,
    ["bob"] = Ratings.InitialRating,
};

// alice побеждает
var (newAlice, newBob) = Ratings.Update(ratings["alice"], ratings["bob"], aWon: true);
ratings["alice"] = newAlice;
ratings["bob"] = newBob;

double p = Ratings.WinProbability(newAlice, newBob);
```

Полный API для каждого языка описан в README соответствующего пакета.

```bash

```

```bash

npm run typecheck  # проверка типов
npm run build      # собрать в dist/
```

```bash
dotnet test csharp/test/DecentralizedBradleyTerry.Tests/DecentralizedBradleyTerry.Tests.csproj
```

Оба набора тестов покрывают формулу прогноза, симметрию, монотонность, сохранение логарифмических шансов, влияние скорости обучения, некорректный ввод и сквозную проверку сходимости онлайн-обновлений к глобальной MLE Брэдли–Терри.
